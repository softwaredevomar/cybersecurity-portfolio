# Cybersecurity Portfolio

Welcome to my cybersecurity portfolio - a look at my journey into cybersecurity.

## Why Cybersecurity?

My interest in cybersecurity began as an extension of my pursuit to become a professional software engineer.
While building iOS apps and web development projects, I realized that mastering cybersecurity principles
would not only enhance the integrity of my software but also make me a more compelling candidate to employers
seeking engineers who understand secure coding practices.

I began exploring how techniques like input interpolation can prevent malicious kernel code injection, and how
forensic awareness can be beneficial in protection. This portfolio reflects that journey, a fusion of software
engineering and cybersecurity.

Explore my work at https://softwaredevomar.github.io

## CTF Experience

My Capture The Flag (CTF) journey began with an apprenticeship application challenge hosted by MaxxPotential,
where I placed first. This indicated I had good problem solving abilities for cybersecurity challenges. That
experience sparked an interest to learning more CTF formats and workflows.

Before participating in MetaCTF, I studied lessons while in the SANS BACS 3002: Portfolio Practicum course
via Canvas, progressing through CTF 101 and CTF 201 Lessons under the guidance of Coach Jacob Elliot.
I documented my learning sessions and began organising my notes into each sections for each category of the
NCL CTF. In MetaCTF, I was still new to the format and solved a single challenge using Linux commands to uncover a
hidden file and displaying its contents to extract the flag. This helped developed some forensics skills.
